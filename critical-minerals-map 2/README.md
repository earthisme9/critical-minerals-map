# 핵심 광물 뉴스 지도

## 내 컴퓨터에서 실행
Python 3.9 이상이 필요합니다. 별도 패키지나 API 키는 필요 없습니다.
터미널에서 압축 해제한 폴더로 이동한 뒤 실행하세요.

```sh
python3 news_service.py
```

브라우저에서 http://localhost:8080 을 열고 뉴스 탭을 선택합니다.
최초 수집은 네트워크 상태에 따라 수 분 걸릴 수 있습니다.
서버가 실행 중이면 시작 시 및 마지막 수집으로부터 24시간마다 수집합니다.
페이지 새로고침 또는 뉴스 새로고침 시 마지막 수집이 1시간 이상 지났으면 백그라운드로 추가 수집합니다.
수집 중에는 기존 기사를 보여주며 5초마다 완료 여부를 확인합니다.
컴퓨터가 꺼져 있으면 수집되지 않습니다. 항상 자동 실행하려면 아래 설정을 사용하세요.

## 컴퓨터가 꺼져 있어도 매일 수집
1. 이 폴더의 내용(숨김 폴더 `.github` 포함)을 GitHub 저장소의 최상위에 올립니다.
2. Actions를 활성화하고 `Daily mineral news` → `Run workflow`를 최초 한 번 실행합니다.
3. 매일 한국시간 07:17 예약 수집합니다. GitHub 사정으로 지연되거나 실행되지 않을 수 있으니 Actions 실패 알림을 확인하세요.
4. 수집 결과는 저장소의 `news.json`에 저장됩니다. 정적 호스팅은 이 파일을 함께 배포해야 합니다.
   Actions 봇의 커밋만으로 다른 배포 워크플로가 실행되지 않을 수 있습니다. 기존 배포가 Actions 기반이면 위 수집 작업 뒤에 배포 단계를 연결하세요.
   이 패키지는 호스팅 계정에 배포하거나 자동화를 활성화한 상태가 아닙니다.

정적 호스팅에서 새로고침은 배포된 JSON을 다시 읽습니다. 즉시 추가 수집은 Python 서버 모드에서 지원합니다.
Python 서버는 로컬 사용용이며 외부 공개용 인증·배포 설정은 포함하지 않습니다.

## 수집과 분류
- 8개 광물군별 한국어·영어 Google News RSS 16개 검색을 서버에서 직접 읽습니다. rss2json 중계 의존을 제거했습니다.
- 최근 14일 검색, URL 기준 중복 제거, 여러 광물에 걸친 기사 통합, 최대 60일·3,000건 보관.
- 일부 검색이 실패해도 기존 데이터 유지. 광물별 정상/빈 결과/일부 실패/실패와 이번 수집 건수 표시.
- NEW는 같은 브라우저의 이전 뉴스 방문 이후 처음 발견한 기사입니다.
- 광물 연결은 검색 결과 기준입니다. 시장·밸류체인은 제목 키워드로 추정하며 태그에 마우스를 올리면 근거 단어가 나옵니다. 원문 전체를 분석하거나 검증한 판정이 아닙니다.
- 포괄적인 희토류 기사, 축약어, 제목에 연결 정보가 없는 기사에는 누락·오분류가 있을 수 있습니다. 미분류를 임의로 채우지 않습니다.
- Google News 단일 공급원이며 한국어/영어는 독립된 공급원이 아닙니다. 서비스 변경이나 접근 제한 시 수집 실패 상태를 표시합니다.
- 기사 전문을 복제하지 않고 제목·출처·날짜·원문 링크를 저장합니다.

한 번만 수집: `python3 news_service.py --collect`
포트 변경: `python3 news_service.py --port 8090`
검증: `python3 -m unittest test_news_service.py`

## macOS 인증서 오류
`CERTIFICATE_VERIFY_FAILED`가 발생하면 python.org에서 설치한 Python의 Applications 폴더 안 `Install Certificates.command`를 실행한 후 다시 수집하세요. 인증서 검증을 끄지 마세요.

## 검증 결과
2026-09-07 실제 Google News RSS에서 8개 광물군 모두 정상 응답을 확인했으며 그 수집 결과를 news.json에 포함했습니다. 중복 병합, 실패 시 데이터 보존, 제목 분류 단위 테스트와 JavaScript 문법 검사를 통과했습니다. 원문 내용의 정확성 및 모든 기사의 관련성을 수동 검수한 것은 아닙니다.
